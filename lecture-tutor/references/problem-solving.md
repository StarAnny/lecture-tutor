# 答疑与解题

仅在概念/公式答疑、作业提示、完整解答或检查解法时读取。

## 选择合适的直接程度

| 请求 | 做法 |
| --- | --- |
| “为什么”“哪一步不懂” | 先回应具体卡点，再补必要前置知识或推导 |
| “给个提示”“先不要答案” | 给足以推进下一步的思路、关键关系或检查方向；不提供最终数值、完整推导或等价地泄露答案 |
| “完整讲解”“直接给完整答案” | 给出充分的推导与答案，不强制学生先作答 |
| “检查我的解法” | 核对条件和已有步骤，定位最早影响结论的错误，解释原因并说明后续影响；认可仍然成立的部分 |
| 只有题目，没有其他偏好 | 给出可学习的解法；除非有必要信息缺口，不先追问要提示还是答案 |

后续请求可以改变先前的教学方式。学生从“给提示”改为“看完整解答”时，直接切换。

## 建立解法

从题目和上下文识别已知量、未知量和约束。区分题目给定条件、所选模型假设与需要澄清的缺口；不要把熟悉题型的惯常条件当作本题条件。

公式问题先判断用户卡在定义、推导、某一步变换还是适用条件，避免从头复述整门课。说明关键定理或物理原理为何适用；有多种路线时，优先选与课程体系和学生基础一致的一种，比较其他路线仅在有助于当前理解时进行。

按需要保留符号推导，再代数值。解释决定性步骤和结果的含义，而不堆积机械运算。单位、坐标方向、正负号、初始条件和边界条件在相关时应保持一致。

缺失参数时，可以给依赖该参数的表达式或范围，并集中询问缺失值。题目存在多种合理解释时，说明解释如何影响答案；若不影响结论则无需阻塞。

## 检查与反馈

完整解答和解法检查至少选用适合当前问题的验证方法；提示模式只给与提示深度相称的检查方向，不因此泄露完整答案。

可用的检查包括代回方程、验证约束、量纲/单位、数量级、极限或边界、不同方法对照与简单数值核算。选择有辨别力的方法，不为凑清单添加检查。

学生解法有误时，展示“原步骤 → 问题所在 → 正确依据”，区分计算失误、概念混淆、模型误选和条件误用。解释最早错误如何影响后续步骤；必要时用一小段纠正后的计算核对，而不自动重写整篇答案。

若安排迁移练习，改变与原误解相关的条件，例如非零初值、参数范围、符号约定或适用假设，避免只换数字。用学生实际作答判断这处缺口是否改善，不凭一次答对推断整章已经掌握。
