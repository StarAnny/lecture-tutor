# 自编课程材料：一阶 RC 电路

本文件是技能试用所用的文字讲义，非用户实际课件。下列“课件第 N 页”是本讲义内的段落标题，不表示测试过 PDF 渲染或真实幻灯片。

## 课件第 1 页：问题与约定

理想电压源经电阻 R 向电容 C 供电。电阻电流 i 的正方向从电源流向电容正极，电容电压为 v_C。t = 0 时输入切换为恒定 U = 10 V。取 R = 2 kΩ，C = 100 μF，v_C(0−) = 2 V。切换没有冲激电流，因此 v_C(0+) = 2 V。

## 课件第 2 页：建立方程

KVL：R i + v_C = U。
电容关系：i = C dv_C/dt。
因此 RC dv_C/dt + v_C = U，适用于切换后 t ≥ 0。

## 课件第 3 页：解与时间常数

令 τ = RC，则 v_C(t) = U + [v_C(0+) − U] exp(−t/τ)。
τ = 0.2 s。一个 τ 后，电压已经完成从初值到终值变化量的约 63.2%，并非总是等于终值的 63.2%。
电流 i(t) = [U − v_C(0+)] / R × exp(−t/τ)。

## 课件第 4 页：零初值传递函数

仅在零初始条件下，以电源电压为输入、电容电压为输出，H(s) = V_C(s)/U(s) = 1/(1 + sRC)。
非零初值的总响应需要同时考虑初始储能。
该理想电路的截止频率 f_c = 1/(2πRC)。
